# Product

## Register

product

## Users

People who paste an existing draft into a text editor and want a clearer, more natural version that preserves their meaning.

## Product Purpose

HumanGPT is a simple writing humanizer with a default browser-local English editor and an optional cloud AI editor. The primary flow is paste, choose tone and edit intensity, rewrite, review, and copy. Adaptive smartness, vocabulary preferences, concision, contractions, sentence variety, and protected terms give writers more control. The offline editor uses conservative rules and a small learned candidate ranker, not a generative language model. It must work without an API key and, after the first successful cache, without a network connection. It is an editor-first application, not a marketing-heavy landing page. The repository is public and the owner will connect it to Render later.

## Brand Personality

Simple, clean, approachable. Use plain, useful language and keep the writing task in focus.

## Anti-references

Avoid visual clutter, elaborate marketing sections, and fabricated AI-detector scores. Do not promise “0% AI,” undetectability, or a guaranteed detector result.

## Design Principles

1. Put the draft and rewrite side by side when space allows.
2. Preserve the writer's meaning and keep them in control of the result.
3. Make the primary task obvious without onboarding or an account.
4. Be honest about local editing, machine-learning scope, AI, deployment configuration, and detector limitations.
5. Show helpful recovery actions for empty inputs, network errors, and missing configuration.

## Accessibility & Inclusion

Baseline implementation target: WCAG 2.2 AA. Use native controls, associated labels, visible keyboard focus, accessible status messages, adequate contrast, a mobile single-column layout, and reduced-motion support. This is an implementation target, not a claim of independent certification.
